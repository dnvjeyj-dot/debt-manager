# 还款提醒（提醒版 1）

入口：主页提醒摘要，或“更多 → 还款提醒”。使用同一个 Safari 和原仓库地址，不迁移账本。

## 行为

- 只读 `debt_manager_hosted_v1`。仅在独立键保存提醒设置、日历导出记录；导航请求用 sessionStorage。
- 默认提前 3 天、提前 1 天、到期当天北京时间 09:00。每个时点生成一个含 DISPLAY VALARM 的独立 VEVENT，不生成循环账单。
- 展示未来 30/60 天以及已有日期的到期未确认事项。信用卡仅用当前已录入账期；完整到期日优先，其次按最近出账日和固定还款日推算并明示。没有账期时按本月固定日期提示核对，不把已过日期自动移到下月。
- 本期已记还清不再生成提醒；已知部分还款继续核对本机剩余。贷款读取明确月供或按本金与利率估算月息，明确标注；月供与本金到期分开显示，不合计。
- 缺日期或标识冲突不能导出。未知金额保持未知，日期提醒仍可用。银行账单适配与本功能独立。
- 过去的提醒时点不补造历史通知；已到期且没有剩余时点时，生成约 5 分钟后的单次核对提醒。

## 日历边界

这是用户操作的一次性 .ics 文件导出，不是后台推送、日历订阅或日历自动同步。网页不能验证 iPhone 是否导入、系统通知权限、或是否实际送达。导出后显示“已生成文件”；只有用户核对系统日历后，才能手动标记“我已在日历确认添加”。

建议先创建专用“债务还款提醒”日历并导入不含财务信息的测试提醒。分享界面若没有日历入口，可通过苹果自带“邮件”导入 .ics，或使用页面内手动添加清单。导入后须核对日程里的提醒没有被系统忽略，并开启日历通知。

还款、金额或日期变化后，站内可检测已生成批次变化，但不能删除或更新系统日历。用户须手动处理旧日程；重复导入可能重复。更换设备或新账期需要在相应设备导出和确认。默认不把金额（包括已记录还款金额）写入日历；开启金额选项时才包含参考数。日历账户可能把导入内容同步到该账户的云端。

## 验证

`node --test tests/repayment-reminders.test.cjs`

44 个纯逻辑测试在发布前执行通过。另做了 Chromium 390×844 离线界面测试：使用合成账本和隔离内存存储，验证表单、日历内容生成、手动确认、变化提示、注入转义、原主程序菜单交互和账本不被写入。没有将合成数据放入用户的账本。此测试不等同于真实 iPhone 日历导入或锁屏通知送达。

本次仅增加提醒模块、启动入口和程序壳缓存；不修改邮件解析、账单同步策略、密钥、账户、额度或原始记账核心。
