# 债务管理器

GitHub Pages 程序壳。本仓库不包含任何私人财务数据。

## 使用

1. 在仓库 Settings → Pages 中选择 `Deploy from a branch`
2. Branch 选择 `main`，Folder 选择 `/ (root)`
3. 用 iPhone Safari 打开 Pages 地址
4. 在程序“数据管理”里导入私人 JSON
5. Safari 分享 → 添加到主屏幕

## 隐私

不要把私人 JSON、备份 JSON、债务余额或应收数据提交到 GitHub。

## 升级

保持同一个仓库和 Pages 地址。以后升级只替换程序文件，不更换网址。升级前建议先在程序内导出 JSON 备份。
